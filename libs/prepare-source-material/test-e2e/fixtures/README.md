# Recorded source pages

These fixtures capture the Anthropic, Cloudflare, and Gates Notes pages on 2026-09-30, and the [source subtitle acceptance set](#source-subtitle-acceptance-set) on 2026-10-28, before source-material cleanup. Each JSON file contains the original response URL, HTTP status, content type, and decoded response body for the page and its completed first-party HTML, JavaScript, CSS, and content API requests. Cloudflare's search modules are also included because the page imports them.

The fixture server serves these responses locally on a port the operating system assigns for each run. The test browser adapter intercepts requests at their original public URLs and fulfills them from that server, preserving production URL validation and relative URL resolution. No browser request falls through to the internet. Images, fonts, video, and third-party analytics are blocked; missing recorded application resources fail the test, except the requests a fixture lists as unrecorded (resources unavailable at capture time, or requests whose query changes on every load), which are blocked. Each page's declared cover image is asserted from its recorded metadata. The image itself is not recorded: a separate test answers the cover image navigation with a one-pixel PNG to verify that a real browser delivers the bytes, referrer, and `Accept` header the loader relies on.

Gates Notes retains its original empty HTML shell, Next.js bundles, and content API responses. Its test verifies that disabling JavaScript leaves the shell empty, without a declared cover image, and that enabling JavaScript produces the article and its declaration. Serving an already rendered DOM would lose this coverage.

Each page asserts that its source title is its visible headline, the first `<h1>` that renders visibly, and that the cut removed the headline and the text above it, such as Gates Notes' eyebrow and Der Standard's kicker. The recorded pages hold no hidden `<h1>`, so a separate test serves a page with hidden headings, including one inside a hidden consent wall, and checks in both load modes that the visible one becomes the source title.

Each page also asserts its source subtitle, by whitespace-normalized equality, or its absence, as listed in the [acceptance set table](#source-subtitle-acceptance-set), and that the prepared HTML no longer contains an accepted source subtitle. The page's metadata descriptions come from the recorded `<head>` and body, so a recording must keep them for the metadata rule to apply.

Run the suite from the repository root:

```sh
pnpm test:e2e:source-material
```

The expected cleaned HTML lives beside the test in one `../<fixture>.html` file per fixture. Update those snapshots only for intentional preparation changes:

```sh
pnpm --filter '@cup/prepare-source-material' test:e2e:update
```

Publisher changes do not require refreshing these fixtures. When deliberately capturing a newer publisher implementation, record a Playwright browser context with `recordHar: { content: "embed", mode: "minimal", path: "capture.har" }`, wait for the article and `networkidle`, then close the context to flush the recording. Keep successful HTML, JavaScript, CSS, and JSON responses from the hosts listed in `createFixtureBrowser`, decode base64 bodies if necessary, and deduplicate by URL into the existing response format. Review changes to the raw inputs and cleaned snapshots together. Preserve the empty Gates Notes navigation response and its scripts rather than replacing them with rendered HTML.

## Source subtitle acceptance set

`derstandard.json`, `openai-developers.json`, `washington-post.json`, and `wikipedia.json` were recorded on 2026-10-28 for the [source subtitle map](https://github.com/patricktree/cup/issues/106) by the procedure above, with a headless Chromium using the test's Linux user agent and no cookies, except `derstandard.json`: without consent Der Standard serves a consent wall, so its page is the operator's browser save ("HTML only") after a consent choice, stored under the story URL, with the first-party scripts and stylesheets it references fetched separately (`b.staticfiles.at/forum/dst-forum/index.js` answered 403 and is missing). The save holds only the scripts the page references, not the chunks they import, so the test lists those as unrecorded; Washington Post's and Wikipedia's session and geolocation requests are unrecorded too. Each keeps only responses from the page's first-party hosts: `www.derstandard.at`, `at.staticfiles.at` and `b.staticfiles.at`; `developers.openai.com`; `www.washingtonpost.com`; `en.wikipedia.org`.
