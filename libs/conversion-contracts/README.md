# Conversion contracts

Runtime-independent conversion concepts shared by accounts, conversion grants, the workflow, and listener API contracts: conversion phases and failures, conversion ownership, audiobook references, measurements, and duration balances.

The root export contains schemas, types, [preparation workflow payload validation](src/preparation-workflow-params.ts), and [artifact-prefix construction and recognition](src/artifact-prefix.ts). Account artifacts share an account root for deletion and have separate conversion prefixes; trial conversions retain their existing storage layout. Workflow, production, delivery, and cleanup callers use these helpers. The `/duration-accounting` export contains the segment-usage shape, duration estimation, and the prepared-conversion status derived from segment states. Both owners persist their duration allowance in the [duration ledger](../duration-ledger/README.md); grant allowance defaults remain in conversion-grants and the account welcome allowance in accounts. This library has no Cloudflare or database dependency.
